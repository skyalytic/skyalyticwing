# Batch Skill

跨多个工作树或子代理的并行工作编排，实现大规模批量操作。

## 使用场景

- 批量文件处理
- 多项目并行操作
- 大规模代码重构
- 批量测试执行
- 多环境部署

## 操作步骤

1. **定义任务列表**
   创建任务数组，每个任务包含：
   - 任务描述
   - 执行命令或操作
   - 工作目录
   - 依赖关系

2. **并行执行**
   使用 `subagent_spawn_swarm` 工具：
   ```
   subagent_spawn_swarm({
     tasks: [
       { task: "任务1", prompt: "执行步骤..." },
       { task: "任务2", prompt: "执行步骤..." },
       { task: "任务3", prompt: "执行步骤..." }
     ]
   })
   ```

3. **串行执行**
   逐个执行任务，适用于有依赖关系的场景

4. **结果汇总**
   收集所有任务结果，生成汇总报告

## 示例

```
用户: 批量更新5个项目的package.json
步骤1: 定义5个更新任务
步骤2: subagent_spawn_swarm({ tasks: [...] })

用户: 并行运行3个项目的测试
步骤1: 定义测试任务
步骤2: subagent_spawn_swarm({ tasks: [...] })
步骤3: 汇总测试结果
```
