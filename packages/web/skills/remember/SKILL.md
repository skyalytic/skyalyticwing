# Remember Skill

审查 AI 自动生成的记忆条目，提出改进建议，优化记忆系统的质量。

## 使用场景

- 审查记忆条目的准确性
- 合并重复的记忆
- 提升记忆条目的描述质量
- 清理过时的记忆
- 优化记忆标签

## 操作步骤

1. **搜索记忆**
   ```
   memory_search({ query: "*" })
   ```

2. **审查记忆质量**
   - 检查描述是否清晰
   - 验证内容是否准确
   - 评估标签是否合适
   - 识别重复条目

3. **改进建议**
   - 合并相似记忆
   - 补充缺失标签
   - 优化描述文字
   - 删除过时信息

4. **执行改进**
   ```
   memory_save({ key: "改进后的主题", content: "改进后的内容", tags: ["优化后的标签"] })
   ```

## 审查清单

- [ ] 记忆描述是否清晰明确
- [ ] 内容是否仍然准确和有用
- [ ] 标签是否覆盖关键主题
- [ ] 是否有重复或相似的条目
- [ ] 是否需要合并或拆分

## 示例

```
用户: 审查我的记忆条目
步骤1: memory_search({ query: "*" })
步骤2: 逐条审查质量
步骤3: 提出改进建议

用户: 清理重复的记忆
步骤1: 搜索所有记忆
步骤2: 识别重复条目
步骤3: 合并并更新
```
