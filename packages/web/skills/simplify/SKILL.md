# Simplify Skill

审查代码变更的复用性、质量和效率，提出简化和优化建议。

## 使用场景

- 代码审查和简化
- 识别重复代码
- 优化算法效率
- 改善代码可读性
- 重构建议

## 操作步骤

1. **读取代码**
   使用 `file_read` 读取目标文件

2. **分析代码质量**
   - 识别重复代码块
   - 检查过长函数
   - 分析复杂度
   - 检查命名规范

3. **提出简化建议**
   - 提取公共函数
   - 简化条件逻辑
   - 使用标准库替代手写代码
   - 减少嵌套层级

4. **生成改进代码**
   使用 `apply_patch` 应用改进

## 审查维度

| 维度 | 检查项 |
|------|--------|
| 复用性 | 重复代码、可提取函数 |
| 可读性 | 命名、注释、结构 |
| 效率 | 算法复杂度、不必要的操作 |
| 安全性 | 输入验证、敏感数据处理 |
| 可维护性 | 耦合度、模块化程度 |

## 示例

```
用户: 简化这个文件的代码
步骤1: file_read({ path: "src/utils.js" })
步骤2: 分析代码质量
步骤3: 提出简化建议
步骤4: apply_patch 应用改进
```
