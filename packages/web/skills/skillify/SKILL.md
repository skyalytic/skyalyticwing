# Skillify Skill

将会话中可重复的操作过程捕获为可复用的技能，实现知识沉淀和流程自动化。

## 使用场景

- 将常用操作流程封装为技能
- 从对话历史中提取可复用模式
- 改进和优化现有技能
- 团队知识共享

## 操作步骤

1. **识别可复用模式**
   - 回顾当前会话的操作步骤
   - 识别重复出现的操作序列
   - 确定通用化的参数

2. **提取操作步骤**
   - 将具体操作抽象为通用步骤
   - 用参数占位符替换具体值
   - 添加条件判断和错误处理

3. **创建技能文件**
   使用 `skill_create` 工具：
   ```
   skill_create({
     name: "技能名称",
     description: "技能描述",
     content: "SKILL.md内容"
   })
   ```

4. **测试技能**
   使用 `skill_execute` 测试新创建的技能

5. **迭代改进**
   根据测试结果优化技能步骤

## 示例

```
用户: 把刚才的部署流程保存为技能
步骤1: 回顾部署步骤
步骤2: 提取通用流程
步骤3: skill_create({ name: "deploy-flow", ... })

用户: 从这个对话中提取一个可复用的模式
步骤1: 分析对话中的操作序列
步骤2: 识别可通用化的部分
步骤3: 创建技能
```
