# Summarize Skill

对各种来源的内容生成精炼摘要，支持URL网页、本地文件、播客转录和长文本。

## 使用场景

- 总结网页文章的核心内容
- 摘要长文档或报告
- 提取PDF文件的关键信息
- 浓缩会议记录或对话历史
- 生成播客或视频的文字摘要

## 操作步骤

1. 确定需要摘要的内容来源：
   - **URL**: 使用 `web_fetch` 获取内容，然后摘要
   - **本地文件**: 使用 `file_read` 读取内容，然后摘要
   - **PDF文件**: 使用 `pdf` 工具提取文本，然后摘要
   - **直接文本**: 直接处理用户提供的文本
2. 分析内容结构，识别关键信息
3. 生成摘要，包含：
   - 核心主题（1句话）
   - 关键要点（3-5条）
   - 重要细节（可选）
   - 结论/建议（如有）
4. 根据用户需求调整摘要长度和详细程度

## 摘要模板

```
## 📋 摘要

**主题**: [一句话概括]

**关键要点**:
1. [要点1]
2. [要点2]
3. [要点3]

**详细内容**:
[可选的扩展说明]

**结论**: [总结性陈述]
```

## 示例

```
用户: 帮我总结这篇文章 https://example.com/long-article
步骤1: web_fetch({ url: "https://example.com/long-article" })
步骤2: 分析内容并生成摘要

用户: 总结这个PDF文件 /path/to/report.pdf
步骤1: pdf({ action: "extract", path: "/path/to/report.pdf" })
步骤2: 分析提取的文本并生成摘要

用户: 简要概括以下内容: [长文本]
步骤1: 直接分析文本生成摘要
```
