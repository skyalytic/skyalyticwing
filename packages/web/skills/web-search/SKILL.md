# Web Search Skill

## 何时使用
- 用户要求搜索某个话题
- 知识库没有相关信息时
- 需要获取最新信息时

## 操作步骤

### 搜索信息
1. **先查知识库**: 用 `knowledge_search(query="关键词")` 搜索
2. **知识库无结果**: 用 `web_search(query="搜索词")` 搜索网页
3. **需要详细内容**: 用 `web_fetch(url="网址")` 获取页面内容

### 优先级
1. 知识库（最快、最相关）
2. 网页搜索（最新信息）
3. 网页抓取（详细内容）

## 注意事项
- 搜索词要精简，不要整句话搜索
- 中文搜索用中文关键词
- 抓取网页时注意内容长度限制
